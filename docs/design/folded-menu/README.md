# Quiqr ChatCMS — folded content menu hand-off

Only two things: the vertical label strip for the folded content column, and
the location picker in the breadcrumb.

1. Copy this folder into the repo, e.g. `docs/design/folded-menu/`.
2. Start Claude Code and paste the prompt from `PROMPT.md`.

| Path | What it is |
| --- | --- |
| `FOLDED-MENU.md` | The spec (strip, picker, acceptance checks). |
| `PROMPT.md` | Kick-off prompt. |
| `tokens/tokens.css` | Design tokens (same as the main kit). |
| `reference/screenshots/` | `content-menu-folded.png`, `content-menu-folded-picker.png`. |
| `reference/html/` | The same two states as static HTML. |
| `reference/canvas-source/` | The Claude Design artboard (`DrawerChosen.dc.html`). |

Sample content (ecosymbia.com-like groups and titles) is illustrative only.
