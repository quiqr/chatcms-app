## Summary of Changes

The editor's view switch is Form, Form + preview, Chat + preview and Preview,
remembered per person per project. Chat + preview puts a 400 px chat column
beside the preview, without the form, or the chat alone where there is no
room. The desktop has no separate Assistant button; the Chat + preview
segment counts running requests. A selection opens Chat + preview.
