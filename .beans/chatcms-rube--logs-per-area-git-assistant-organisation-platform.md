Following chatcms-qru3 (`openspec/changes/project-log`), which keeps preview
starts and gives a project a Log page with starts, builds and publications.
Agreed on 20 November 2026: one log page per area, on one way of keeping
entries, each shown to whoever belongs to that area.

- **Project, git level** (implementers): fetches, sends, catching up,
  conflicts, going back; branch, head and remote state over time.
- **Project, assistant** (implementers): asks, changes made, stops, tokens.
- **Organisation** (organisation admins): people in and out, roles,
  projects made, moved or archived.
- **Platform** (platform admins): fold the existing History (administration
  records) and workspace events into a Log.
- **Access** (platform admins, and each person for themselves): sign-ins,
  failed sign-ins, sessions. Personal data: a short retention, stated.

Each gets its own change; the shared model from project-log is reused.
