Claude Design reads the llms.txt on chatcms.eu, which tells it to ask the user for an import link. The user makes the link in ChatCMS; it carries a one-time token tied to an organisation, so no sign-in is needed. Claude Design uploads a package (HTML, CSS, assets, and an optional manifest listing the pages and what each is for), and ChatCMS makes a new project from it.

Source: `~/secondbrain/content/quiqr_chatcms__claude_design_import_en_conversie.md`. Draft: how this is done is still to be discussed.
